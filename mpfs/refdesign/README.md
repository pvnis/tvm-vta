# Libero flow for the VTA-on-PolarFire design

Copies of the scripts that live in `refdesign-vta/`, which is a working copy of Microchip's
Discovery Kit reference design and has no remote of its own. They are kept here because this
repository is the only one in the sandbox that is pushed anywhere.

What is NOT copied, because it is large and reproducible:

  - `refdesign-vta/MPFS_DISCOVERY*/` - Libero projects and build output. Regenerated by
    `full_rebuild.sh`, which starts from the pristine reference design every time.
  - `refdesign-vta/vta_hw/VTA.DefaultPynqConfig.sv` - the synthesis Verilog, generated from
    the Chisel in this repo by `mpfs/rebuild_rtl.sh -v`.

## Layout

    full_rebuild.sh        regenerate base design -> integrate VTA -> build -> checks
    build_check.sh         build + programming data, then refuses to hand over a build
                           unless REF_CLK is on R18 and the timing report contains VTA paths
    vta_integrate.tcl      adds VTA to the FIC_0_PERIPHERALS SmartDesign (125 MHz, direct)
    vta_integrate.tcl.125mhz.bak   the same, kept as the known-good fallback
    script_support_vta/    component configs: interconnect ports, the 100 MHz VTA PLL,
                           the CDC bridges (unused), and vta_clocks.sdc
    vta_build.tcl / vta_prog.tcl / vta_program.tcl / vta_program_run.sh
                           synthesis+P&R+timing / programming data / program the device
    iterate_integrate.sh   fast loop on the integration step only
    full_100mhz.sh, build_100mhz.sh, build_multipass.sh, restore_125mhz.sh
                           earlier experiments: dedicated 100 MHz PLL with CDC (regressed the
                           ALU), multi-pass P&R, and restoring the 125 MHz project

To rebuild from scratch: copy these into `refdesign-vta/` beside a checkout of the reference
design, apply `../tvm-v0.18.0-mpfs.patch` to TVM v0.18.0, then run `mpfs/rebuild_rtl.sh -v`
followed by `full_rebuild.sh`.
